# KaisabaBuild プラグイン

## 注意事項
これはかい鯖グループの「建築バトル鯖」で使用するため作成したプラグインです。
他の環境で動くことは保証できません、ご了承ください。

## 概要
WorldEditも使える建築バトル用プラグイン！
キューに参加して一定人数になるとゲームが開始して自分のプロットに建築できます。
建築フェーズが終了すると評価フェーズに入ります。
評価フェーズではほかの人の建築を評価できます。
